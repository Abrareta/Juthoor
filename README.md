# جذور (Juthoor)

بروتوتايب تفاعلي — هاكثون هيلثون 2026 (مسار الصحة الرقمية للمرأة)

## الفكرة

منصة رقمية مستقلة تفتحها المرأة مباشرة بدون تسجيل مسبق. تبني شجرة عائلة تفاعلية لقريباتها المصابات بسرطان الثدي أو المبيض، ومحرك مبني على **Manchester Scoring System** (معيار سريري معتمد، تم التحقق من جدول نقاطه من مصدرين مستقلين: NHS Genomics Education وملحق مراجعة USPSTF بـ NCBI) يحسب درجة الخطورة الوراثية ويوضح سبب التصنيف. الخطورة العادية توصي بفحص تصويري روتيني (ماموغرام)، والخطورة العالية تفتح مسار إحالة لأقرب جهة معتمدة تقدّم الفحص الوراثي (BRCA) والاستشارة الوراثية، مع تتبّع حالة الإحالة من طرف المريضة ولوحة مراجعة من طرف الطبيب.

هذا نطاق **الطبقة الأولى (Layer 1)** فقط — أساسيات قابلة للعرض بالهاكثون. لا يوجد تكامل فعلي مع أي جهة خارجية، ولا بيانات مريضات حقيقية.

### إضافات V2

- إرفاق ملف جيني اختياري (VCF / FASTQ / PDF) بمرحلة شجرة العائلة — **حقل تجريبي بحت**: يُرفق كبيانات وصفية (الاسم والحجم) فقط لمراجعة الفريق الطبي يدويًا، ولا يُحلَّل داخل المتصفح ولا يُستخدم بحساب النقاط الآلي.
- بعد نتيجة الخطورة العالية: زر توليد ملخص تقرير (طباعة/PDF عبر متصفح)، بطاقة اختيار مسار الإحالة المُفضّل (المسار الصحي أو المسار الوطني عبر برنامج الجينوم السعودي)، وزر دعوة القريبات للتقييم (رابط تجريبي بنطاق وهمي واضح).
- تتبّع الإحالة الحيّ وسّع لأربع مراحل: تقديم الطلب ← مراجعة طبيب جذور ← التحويل للمستشفى/برنامج الجينوم ← جاهز لاستشارة BRCA، مع قدرة الطبيب على توجيه المريضة لأحد المسارين من لوحته.
- استكمال جدول Manchester الموثّق: أضيفت أنواع الإصابة الذكورية (سرطان الثدي الذكوري، البروستاتا) والبنكرياس، مع صلات قرابة ذكورية جديدة (الأب، الأخ)، وفلترة تلقائية لخيارات نوع الإصابة حسب جنس القريب المختار.

### هوية V3 — إعادة تصميم كاملة

أُعيد تصميم الواجهة بالكامل لتشعر كمنتج صحي رقمي متقدّم (Premium Digital-Health Product)، دون أي تعديل على منطق حساب النقاط أو تدفّق البيانات:

- **نظام ألوان دافئ**: عاجي/بيج فاتح كخلفية أساسية، وتدرّجات عنّابي مطفأ + طوبي + سج + زيتوني كألوان تمييز — بلا أي تدرّج صارخ أو خلفيات داكنة/نيون. الوضع الداكن (اختياري تلقائيًا حسب نظام المستخدم، أو عبر تبديل يدوي) يستخدم لوحة "شفق دافئ" (بنّي/كستنائي غامق) بدل الأسود أو الكحلي التقني.
- **خط عربي موحّد**: IBM Plex Sans Arabic في كل الواجهة.
- **خلفية عضوية هادئة**: خطوط تفرّع رفيعة جدًا (مستوحاة من فكرة الجذور والامتداد العائلي) بشفافية منخفضة جدًا وحركة بطيئة جدًا (SVG + CSS)، تُعطَّل تلقائيًا مع `prefers-reduced-motion`.
- **علامة جذور الجديدة**: بنية تفرّع مجرّدة (جذر واحد يتفرّع إلى عُقد) بدل أي رسم حرفي لورقة أو شجرة.
- **صفحة رئيسية جديدة (Landing)**: تخطيط تحريري غير متمركز، مع تمثيل بصري عضوي لشجرة عائلة، وفقرة "كيف يعمل جذور" بثلاث خطوات، وفصل بصري واضح منذ أول شاشة بين الفحص التصويري والفحص الوراثي.
- **شجرة عائلة بصرية بالكامل**: عُقد متصلة بخطوط فروع (خط أمومي بلون عنّابي، خط أبوي بلون زيتوني، الإخوة/الأخوات يُعرضون بصف مشترك) بدل قائمة بطاقات نموذج مكدّسة — الضغط على أي عقدة يفتح لوحة جانبية سياقية لتعديل بياناتها.
- **نتيجة أوضح علميًا**: عرض النتيجة كرقم وتصنيف واضحين (لا عدّاد دائري كبير)، مع صف تمييز صريح بين مسار الفحص التصويري ومسار الفحص الوراثي في كل شاشة ذات صلة (الموافقة، النتيجة)، ولغة هادئة غير مُخيفة عند الخطورة العالية.
- **لوحة الطبيب** بإطار "دعم قرار سريري" (ملخصات حالات مريضات) بدل شكل لوحة تحكم إدارية عامة.
- **تتبّع الإحالة** كمسار زمني (Timeline) بدل شريط مراحل مجزّأ.
- بطاقات أقل وأكثر قصدية (مساحات بيضاء وفواصل بدل تكديس صناديق مستديرة).

## التشغيل محليًا

لا يحتاج أي تثبيت أو بناء (Build) — ملفات ثابتة بالكامل (HTML/CSS/JS بدون أي إطار عمل خارجي).

```bash
python3 -m http.server 8000
# ثم افتحي http://localhost:8000
```

أو افتحي `index.html` مباشرة من متصفحك.

## هيكلة الملفات

```
index.html          نقطة الدخول
css/style.css        نظام التصميم V3 الكامل (الألوان، الخطوط، الخلفية العضوية، الوضع الفاتح/الداكن)
js/icons.js            مكتبة أيقونات SVG مشتركة (بأسلوب Lucide) بدل الاعتماد على مكتبة خارجية
js/data.js            البيانات المرجعية وجدول نقاط Manchester الموثّق + بيانات وهمية (أطباء، مسارات الإحالة، إلخ)
js/scoring.js         محرك حساب Manchester Scoring
js/state.js           إدارة حالة التطبيق (مع حفظ محلي اختياري بالمتصفح)
js/tracker.js         مكوّن المسار الزمني (Timeline) المشترك لتتبع مراحل الإحالة (4 مراحل)
js/landing.js          المرحلة 0: الصفحة الرئيسية (Landing)
js/consent.js         المرحلة 1: الدخول والموافقة الصريحة
js/tree.js             المرحلة 2: شجرة العائلة البصرية (عُقد وفروع) + اللوحة الجانبية لتعديل قريبة + إرفاق الملف الجيني الاختياري
js/results.js          المرحلة 3: نتيجة التقييم + صف تمييز تصويري/وراثي + اختيار مسار الإحالة المُفضّل
js/dashboard.js        لوحة الطبيب: دعم قرار سريري، تعيين المسار، وتتبع الإحالة
js/report.js           توليد اللوحة الجانبية لملخص التقرير القابل للطباعة
js/invite.js           توليد اللوحة الجانبية لدعوة القريبات للتقييم
js/app.js               الربط والتنقل بين المراحل، النوافذ/اللوحات الجانبية، والخلفية العضوية المتحركة
artifact.html         نسخة مخصصة للنشر كصفحة معاينة حية (نفس المنطق، غلاف HTML مختلف)
```

## بيانات وهمية بالكامل

لا يحتوي المشروع على أي مفاتيح API حقيقية أو بيانات مريضات فعلية. أسماء الأطباء ورموز الإحالة كلها تجريبية. رمز دخول لوحة الطبيب (`1234`) رمز عرض توضيحي فقط، وليس آلية مصادقة حقيقية.

## خارطة الطريق (خارج نطاق البروتوتايب الحالي)
